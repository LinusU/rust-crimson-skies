# F23: Avian integration, collision, and fixed-step authority

**Target:** 2000 PC original-data reimplementation. **Initial status:** not implemented; not original-verified.
**Prerequisite features:** F00, F16, F22.
**Owner paths:** `crates/cs_app/src/physics/`; `crates/cs_sim/src/collision.rs`; `crates/cs_app/tests/physics/`.
**Shared contract:** [FLIGHT-PHYSICS](../docs/contracts/FLIGHT-PHYSICS.md).

## Deliverable and interfaces

Avian is the sole rigid-body pose integrator for dynamic aircraft. Gameplay computes force/torque and authoritative impulses; the adapter applies them in the verified physics pre-step schedule. Presentation reads interpolated poses afterward. Fixed simulation rate is initially 120 Hz, a designed baseline subject to documented convergence testing.

## Non-negotiable behavior

1. Never combine manual Transform integration with an Avian dynamic body. Scripted actors use a distinct kinematic/trajectory mode and controlled transitions.
2. Declare collision layers for aircraft, projectiles, static world, debris, triggers and cameras. Sensor overlap is not damage by itself.
3. Use continuous collision/swept tests for fast projectiles and narrow triggers. Tunneling fixes must not globally inflate hitboxes.
4. Mass, center of mass and inertia reflect normalized loadout/airframe data or explicit calibrated approximations. Do not trust autogenerated convex mass for every plane.
5. Physics schedule ordering is pinned to the actual Bevy/Avian API verified in F00; integration tests assert one integration per tick and no hidden variable dt.

## Acceptance tests

These are minimum discriminating tests. Add regression cases for every discovered variant. Tests call production code, not parallel test-only implementations. They must be selected with a nonempty task-specific test prefix and must fail when the relevant behavior is removed.

**AC01:** Apply a known force to a known synthetic mass and verify delta-v once per tick.
**AC02:** High-speed crossing of a thin wall/trigger is detected exactly once.
**AC03:** Switch kinematic to dynamic on aircraft release without a pose or velocity discontinuity.
**AC04:** Run 60/120/240 Hz convergence probes before freezing tolerances.
