# Feature specification index

65 feature contracts, each with four separately gated stages. The task DAG (one task per stage, e.g. `F05-B`) lives in Rally; task keys match the stage headings here. Stage C means implementation integration; stage D adds feature evidence. Neither automatically means original verification. The F64 existing-save-import enhancement is optional; custom-plane data needed by original content remains required.
