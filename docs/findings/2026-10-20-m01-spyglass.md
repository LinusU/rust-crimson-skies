## Implemented (`mission_session/spyglass.rs`, `actor_census.rs`)

* A second `Camera3d` renders into a 256×256 image shown as a round
  `ImageNode` with the target's coloured ring, anchored at the edge point of
  the off-screen arrow. It is inactive unless the window is shown.
* Pose: at the player's position looking at the selected target (look-at
  construction inferred, not traced).
* FOV: `2*atan(1.1*r/d)` clamped to [1.5°, 90°]; radius never exceeds its
  previous value for the same target; r from the target's mesh boxes.
* Window iff target off screen (projection test) and within
  `spyglass_window_threshold`; on screen only the bracket marker is drawn.
* Size table (mode 0/2/3 × flag) and `Shift+S` toggle (exact modifier match).
* Smoke checks `target_spyglass_window` and `target_spyglass_toggle`
  (frames `target_off_view`, `target_spyglass_hidden`).
