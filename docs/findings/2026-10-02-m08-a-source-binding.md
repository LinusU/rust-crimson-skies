## What is different at M08

- **The two localized spellings differ by a word.** The short name reads
  `The Petrol Plot`; the region-prefixed long name of the same campaign
  position reads `… The Petrol Pit`. The declared discovery title matches the
  short-name row verbatim, so production code confirms it by exact comparison
  and does not need the second-form rule M05-A added. Which of the two the
  original game shows where is **not established**; neither is chosen over the
  other here, and nothing keys on either string at runtime. This is the same
  kind of discrepancy the sheet warns about for M18 (the original localized
  string wins).
- **The position is interior.** M06-A bound position 5, where the layout's
  chapter boundary and the long names' region boundary coincide. M08 is
  position 7, the third mission of chapter 2:
  `accept_m08_a_the_position_is_interior_to_the_second_chapter_and_its_region_group`
  asserts both structures give the chapter positions 5..10, with the previous
  and next positions in the same chapter.
- **The world group is shared.** `world/c2` also holds M06's mission, so the
  world row does not identify M08; chapter 2's fifth mission lives in `c2b`
  (role of that directory not established). The binding cites only its own
  program archive.
